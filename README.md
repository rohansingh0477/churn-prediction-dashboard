# Churn Prediction Dashboard

A Flask web application that analyses customer churn data, calculates churn risk metrics, and displays the results in a simple dashboard.

## Features

- Loads customer data from a CSV file
- Processes churn-related data using Python and Pandas
- Calculates average churn probability
- Identifies high-risk customers
- Groups churn rate and high-risk customers by state
- Displays results through a Flask web interface
- Saves analysis output to a text file

## Technologies Used

- Python
- Flask
- Pandas
- scikit-learn
- HTML templates
